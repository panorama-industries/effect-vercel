# @panorama-industries/effect-vercel-core

Shared Effect building blocks for the [effect-vercel](https://github.com/panorama-industries/effect-vercel)
service SDKs: Vercel environment, OIDC credentials, API client, errors and test utilities.

You usually get this package as a dependency of a service package such as
[`@panorama-industries/effect-vercel-queue`](https://www.npmjs.com/package/@panorama-industries/effect-vercel-queue).

```bash
pnpm add @panorama-industries/effect-vercel-core effect
```

## Requirements

- `effect` `^4.0.6` (peer dependency)
- ESM only
