# @panorama-industries/effect-vercel-queue

Effect-native client for [Vercel Queues](https://vercel.com/docs/queues): typed topics, producers,
push and poll consumers. Part of [effect-vercel](https://github.com/panorama-industries/effect-vercel).

```bash
pnpm add @panorama-industries/effect-vercel-queue effect
```

## Requirements

- `effect` `^4.0.6` (peer dependency)
- Vercel CLI `59.26.0` or above
- ESM only
